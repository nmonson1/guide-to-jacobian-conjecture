# A Log-Canonical Cubic Defect Reduces to the Abelian Nine-Cusp Model

<p class="dek">Assume a zero-dimensional log-canonical resolvent center admits the stated equivariant plt extraction with canonical cyclic cover. Nonneutral conormal residues are maximal Cohen-Macaulay by positivity; if a neutral three-torsion eigensheaf has nonzero H1, S3 symmetry forces its cyclic cover to be an abelian surface. In the multiplicity-six double-plane model the branch tangent sextic is then the nine-cuspidal dual of a smooth plane cubic.</p>

## Exact statement

Assume a zero-dimensional log-canonical resolvent center admits the stated equivariant plt extraction with canonical cyclic cover. Nonneutral conormal residues are maximal Cohen-Macaulay by positivity; if a neutral three-torsion eigensheaf has nonzero H1, S3 symmetry forces its cyclic cover to be an abelian surface. In the multiplicity-six double-plane model the branch tangent sextic is then the nine-cuspidal dual of a smooth plane cubic.
