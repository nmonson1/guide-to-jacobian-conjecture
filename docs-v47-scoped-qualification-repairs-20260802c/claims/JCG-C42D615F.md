# The local F2 defect recurrence is integrable: for every m at least two it has an explicit nontrivial finite-support solution, so no obstruction based only on this local finite-order recurrence can eliminate the family.

<span class="status status-kind">Claim</span> <span class="status status-draft">Recorded</span> <span class="status">Core</span>

## Exact statement

The local F2 defect recurrence is integrable: for every m at least two it has an explicit nontrivial finite-support solution, so no obstruction based only on this local finite-order recurrence can eliminate the family.
