# Regular Binary Quartic Pencils Are Automorphic

<p class="dek">In the binary target-span-two locus, if U=J(Q,R), V=J(P,R), and W=J(P,Q) are all nonzero and gcd(U,V,W)=1, then the quartic Keller map is a polynomial automorphism.</p>

## Exact statement

In the binary target-span-two locus, if U=J(Q,R), V=J(P,R), and W=J(P,Q) are all nonzero and gcd(U,V,W)=1, then the quartic Keller map is a polynomial automorphism.
