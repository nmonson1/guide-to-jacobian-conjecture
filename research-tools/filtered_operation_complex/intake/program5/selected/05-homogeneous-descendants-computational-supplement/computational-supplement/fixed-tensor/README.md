# Jacobian five-attacks certificate package

This directory contains the report and exact verification scripts for five
follow-up attacks on the 19-dimensional cubic-homogeneous reduction:

1. the dimension-five classification problem;
2. rank-compressed suspension and cubic-jet obstruction;
3. generic Jordan structure and degeneration;
4. a 38-dimensional Hessian-nilpotent quartic with explicit inverse/Laplacian coefficients;
5. catalecticant bounds and a 110-dimensional square-zero Drużkowski pairing.

Run:

```bash
./run_all.sh
```

Main mathematical narrative: `REPORT.md`.

Compact pairing data are in `pairing_110.json`; fully expanded matrices and the transferred collision are in `A_110.tsv`, `B_110.tsv`, `D_110.tsv`, `C_110.tsv`, and `collision_110.tsv`.
