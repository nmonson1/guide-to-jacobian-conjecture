# One Polynomial Map Encodes Every Bounded Root-Translation Orbit

<p class="dek">At ambient bound N, degree-preserving cubic-frame root translations are exactly the kernel pair of (Qhat,P) mapping to (Qhat,z^N P mod Qhat); when roots escape to infinity, P decomposes uniquely into finite-root data plus the translated principal part.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof offered — review pending</span> <span class="status">Core</span>

## Exact statement

At ambient bound N, degree-preserving cubic-frame root translations are exactly the kernel pair of (Qhat,P) mapping to (Qhat,z^N P mod Qhat); when roots escape to infinity, P decomposes uniquely into finite-root data plus the translated principal part.
