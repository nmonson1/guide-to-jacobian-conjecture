# Quartic High-Ramification and Edge Exclusions

<p class="dek">Conditional on the recorded target-span-two routing, primitive binary ramification degrees four and five are automorphic; fourth-power and zero-minor boundaries add no counterexample leaf. Exact programs certify the encoded determinant and projective-incidence calculations, not global exhaustiveness.</p>

<span class="status status-kind">Result</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

Assume the Program 2 structural reductions place a quartic Keller map in the primitive coprime binary-pencil locus, with H4=(P,Q,0), P,Q in k[x,y]_4 coprime, R=(H3)_3 in k[x,y]_3, U=J(Q,R), V=J(P,R), W=J(P,Q), and r=deg gcd(U,V,W). If r is four or five, then the full Keller map is a polynomial automorphism.

The highest Keller equation routes the cubic and, when necessary, quadratic normal layers to an aligned pure-power, binary, or quadratic-source branch; under the recorded Program 2 inputs every resulting branch is automorphic or already excluded.

### [JCG-5E7E9377 · Assume the Program 2 binary target-span-two reduction. If one of U=J(Q,R), V=J(P,R),…](../claims/JCG-5E7E9377.md)

Assume the Program 2 binary target-span-two reduction. If one of U=J(Q,R), V=J(P,R), or W=J(P,Q) vanishes, including the separate case R=0, then the quartic Keller map is a polynomial automorphism. Consequently the ordinary common-ramification filtration may be applied only after these zero-minor boundaries are removed.
