# Why the Nineteen-Variable Descendant Resists Compression

<p class="dek">After separating row-killing automorphism directions, a six-dimensional exact rank-six cone remains; every point integrates through cubic order, while a universal quartic cokernel functional blocks the entire transversal.</p>

<span class="status status-kind">Result</span> <span class="status coverage-not_applicable">No program manuscript claimed</span>

## Precise statement

In the displayed six-dimensional transversal, the exact rank-six cone is the reduced union V(u3,u5) union V(u0,u3) union V(u2,u5); every point integrates to an exact cubic rank-six jet, but the universal quartic cokernel functional Gamma_4 is identically -1, so no member lifts through quartic order.
