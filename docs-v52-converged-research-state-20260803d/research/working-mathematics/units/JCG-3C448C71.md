# Assume the Program 2 reductions reach a binary leading pencil H4=(P,Q,0) whose…

`JCG-3C448C71` · `assertion` · statement version `1`

## Exact statement

Assume the Program 2 reductions reach a binary leading pencil H4=(P,Q,0) whose greatest common divisor G has degree two and whose residual binary quadrics are coprime. Then the residual pencil is a secant of the Veronese conic and may be normalized to P=x^2G, Q=y^2G; the generic first-normal complement and all four exceptional divisors QF1 through QF4 contain no counterexample, so the full Keller map is a polynomial automorphism.
