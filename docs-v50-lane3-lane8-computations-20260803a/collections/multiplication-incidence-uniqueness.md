# Uniqueness in the Multiplication-Incidence Construction

<p class="dek">Within the binary two-block multiplication-incidence construction U_{a,b,H}, stable affineness, and hence affineness, occurs only for the unordered pair {a,b}={1,2}.</p>

<span class="status status-kind">Result</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

Within the binary two-block multiplication-incidence construction U_{a,b,H}, stable affineness, and hence affineness, occurs only for the unordered pair {a,b}={1,2}.
