# The Fixed-Component Plücker Boundary Is Eliminated

<p class="dek">For H4=(0,0,x^2y^2) with the cubic fixed-component pencil generated by x^2y and xy^2, the Keller equations force the third column of the linear part to vanish; hence this chart cannot occur for a Keller map with invertible linear part.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Recorded</span> <span class="status">Core</span>

## Exact statement

For H4=(0,0,x^2y^2) with the cubic fixed-component pencil generated by x^2y and xy^2, the Keller equations force the third column of the linear part to vanish; hence this chart cannot occur for a Keller map with invertible linear part.
