# Primitive Binary Ramification Four and Five Is Automorphic

<p class="dek">Assume the Program 2 structural reductions place a quartic Keller map in the primitive coprime binary-pencil locus, with H4=(P,Q,0), P,Q in k[x,y]_4 coprime, R=(H3)_3 in k[x,y]_3, U=J(Q,R), V=J(P,R), W=J(P,Q), and r=deg gcd(U,V,W). If r is four or five, then the full Keller map is a polynomial automorphism.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof supplied</span> <span class="status">Core</span>

## Exact statement

Assume the Program 2 structural reductions place a quartic Keller map in the primitive coprime binary-pencil locus, with H4=(P,Q,0), P,Q in k[x,y]_4 coprime, R=(H3)_3 in k[x,y]_3, U=J(Q,R), V=J(P,R), W=J(P,Q), and r=deg gcd(U,V,W). If r is four or five, then the full Keller map is a polynomial automorphism.
