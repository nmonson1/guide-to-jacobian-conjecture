# The Jacobian conjecture

<p class="dek">Every polynomial map from complex affine n-space to itself whose Jacobian determinant is a nonzero constant is a polynomial automorphism.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof supplied</span> <span class="status">Headline</span>

## Exact statement

Every polynomial map from complex affine n-space to itself whose Jacobian determinant is a nonzero constant is a polynomial automorphism.

Statement version `1`. The public tag is stable; statement revisions increment the version rather than replacing the tag.
