# Lane 5: Intrinsic degree and valuative budgets

## Research objective

Connect finite-cover or boundary data to ordinary coordinate degree in a way
that survives arbitrary polynomial left-right equivalence. The target is an
intrinsic lower bound on the whole orbit, or a canonical normalization that
does not increase degree, rather than a budget for one presentation.

Fix polynomial rings

```text
A = k[u1,u2,u3],        B = k[x1,x2,x3]
```

and the injective pullback `iota:A -> B` of a dominant polynomial map. The
degree-bearing object is the **embedded inclusion** `iota:A -> B`, not the
abstract image algebra: abstractly `iota(A)` is again a polynomial ring. A
target automorphism changes the coordinate frame of `A`; a source
automorphism moves the embedded subalgebra inside `B`.

Define

```text
d_LR(iota) =
  min over sigma in Aut(B), tau in Aut(A)
  of max_i deg_x sigma(iota(tau(ui))).
```

A Lane 5 budget should be left-right invariant and bounded above by
`d_LR(iota)`, or arise from a canonicalization whose output degree never
exceeds its input degree.

This lane overlaps [Program 2](minimum-degree-and-quartic-exclusions.md),
[Program 4](stable-moduli.md), and
[Program 6](plane-boundary-obstructions.md). It may also constrain
[Lane 6](homogeneous-realization-compression.md).

## Reusable mathematics

For a source automorphism `sigma`, define

```text
F_d^sigma A = {a in A : deg_x sigma(iota(a)) <= d},
C_d^sigma   = k[F_d^sigma A].
```

The first object is a filtered vector space, not generally a subalgebra. Thus
the precise interpretation of `trdeg A_(<=6) <= 2` is

```text
trdeg_k C_6^sigma <= 2.
```

### Exact standard-source theorem

For the displayed map `F=(P,Q,R)` in its standard source coordinates, the new
hash-pinned fiber certificate proves, over every characteristic-zero field,

```text
k[P,Q,R] intersect k[x,y,z]_(<=6) = span_k{1,Q,R}.
```

Hence the algebra generated by the standard degree-six piece is exactly
`k[Q,R]` and has transcendence degree two. This has no target-polynomial-degree
cutoff.

The proof uses all 84 source monomials of degree at most six and 81 exact
rational common-fiber difference rows. An `81 x 81` minor is `214012` modulo
`1000003`, so the rational matrix has rank 81. Its exact kernel contains
`1,Q,R`, hence equals their span. Every element of `k[P,Q,R]` is constant on
the chosen fiber pairs. The verifier and row data are at

```text
research-notes/lane5-degree-budgets/
```

with SHA-256-pinned Python and JSON files. This is a theorem for the standard
source filtration, not for arbitrary source automorphisms.

### Exact bounded elementary-shear family

The same fiber method now certifies 42 non-affine source presentations:
the six coefficient-one shears

```text
z -> z+x^N, y -> y+x^N, x -> x+y^N,
z -> z+y^N, y -> y+z^N, x -> x+z^N
```

for `2<=N<=8`. In every case the degree-six intersection is either `k` or
`span_k{1,sigma(R)}`; the certificate has rank 83 or 82 respectively.
Therefore none contains a degree-six target coordinate frame. This is an
exact bounded family, not coverage of arbitrary coefficients, exponents,
compositions, or wild automorphisms. The verifier and expected minors are in
the same research-note directory.

### Exact orbit-degree criterion

**Lemma.** If `d_LR(iota) <= D`, then `C_D^sigma=A` for some source
automorphism `sigma`.

**Proof.** Choose `sigma,tau` realizing degree at most `D`. The three target
coordinates `tau(ui)` lie in `F_D^sigma A` and generate `A`. Thus
`C_D^sigma=A`. ∎

Consequently,

```text
if trdeg_k C_D^sigma <= 2 for every sigma in Aut(B),
then d_LR(iota) >= D+1.
```

At `D=6`, a universal theorem would prove orbit-minimal degree seven for the
fixed map. It would not prove a lower bound for every Keller counterexample or
every affine realization of the same finite normalization.

### Filtered differential obstruction

Choose a basis `f1,...,fm` of `F_D^sigma A` and let

```text
J_D^sigma =
  ideal of the 3 x 3 minors of (partial fi / partial uj).
```

This ideal is basis-independent. In characteristic zero,
`J_D^sigma=0` exactly when `trdeg C_D^sigma <= 2`. If the filtered piece
contains a polynomial coordinate frame, then `J_D^sigma=A`; therefore any
proper `J_D^sigma` obstructs such a frame. This is strictly stronger than
transcendence degree: for `span{u^2,u^3,v,w}` the generated algebra has
transcendence degree three but the minor ideal is `(u)`.

This gives a precise residual target for a filtered conormal, Wronskian, or
conductor theorem: prove `J_6^sigma` is proper in every remaining normalized
case. The standard-source certificate proves the stronger statement
`J_6=0`.

### Valuative minimax formula

For a divisorial valuation `v` at infinity, put
`delta_v(f)=max(0,-v(f))`. For source and target coordinate frames `x'` and
`u'`, let

```text
M_v(x')       = max_i delta_v(xi'),
M_v(iota(u')) = max_j delta_v(iota(uj')).
```

Then

```text
deg_x' iota(u') =
  sup_v M_v(iota(u')) / M_v(x').
```

The upper bound follows termwise from the valuation inequality; equality is
attained by the hyperplane-at-infinity valuation for the frame `x'`.
Minimizing over both frames gives `d_LR(iota)`.

All valuations are exact but ineffective. More sharply, **every finite
valuation family fails** under this normalization. Over an infinite field,
choose a linear form having minimal value simultaneously for the finite
family, complete it to coordinates `(ell,y,z)`, and apply
`y -> y+ell^N`. The denominators grow linearly in `N` while the numerator is
fixed, so the normalized infimum is zero. A viable boundary budget must use
an infinite or global boundary object, change the normalization, or first
restrict source frames by a non-degree-increasing canonicalization.

### Rees and functoriality fences

If an exhaustive multiplicative filtration on `B=k^{[3]}` has
`dim G_d=binomial(d+3,3)` in every degree and `gr_G B` is generated in degree
one, its associated graded ring is a polynomial ring and the filtration is
ordinary degree in lifted polynomial coordinates. Thus “simplex-bounded” is
not broader under those axioms.

There is also no fixed exhaustive filtration by finite-dimensional pieces
that is invariant under every polynomial automorphism: if one piece contains
`x1`, invariance under `x1 -> x1+x2^N` would place every `x2^N` in that same
finite-dimensional piece. A generalized filtration must be assigned
covariantly to the embedded pair or chosen by canonicalization.

The companion/Jordan moment budget remains a useful Program 2 audit lens, but
its determinant-arc hypotheses are presentation-sensitive. The source
volume-form value `-4` is only a necessary anchor and does not recover
coordinate pole orders, the value semigroup, or the affine opening.
