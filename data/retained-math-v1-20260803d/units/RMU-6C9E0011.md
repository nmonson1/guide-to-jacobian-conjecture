# Parameter-complete obstruction criterion for an F2 attachment block

`RMU-6C9E0011` · `lemma`

## Mathematical record

`RMU-6C9E0011` · `lemma`

At any fixed normal order r of an F2 attachment recurrence, after all lower-order data are evaluated, write the exact affine system as [C_r | P_r](x_r,p_r)=b_r, where C_r contains endpoint and overlap correction columns and P_r contains every fresh-parameter column. The intrinsic obstruction space is ker([C_r | P_r]^T)=ker(C_r^T) intersect ker(P_r^T). Therefore a left-null functional for the zero-fresh-parameter slice C_r x_r=b_r proves an intrinsic obstruction only if it also annihilates P_r; if its pairing with P_r is nonzero, the apparent obstruction may be cancelled by a fresh parameter. After C5 character decomposition, full attachment at order r is feasible exactly when every complete character block has equal matrix and augmented rank.

Hypotheses:

- All lower-order nonlinear terms have been evaluated into the exact right-hand side and known matrix coefficients.
- C_r includes every endpoint, overlap, normalization, finite-support, presentation, and descent row required at order r.
- P_r includes every fresh order-r parameter column with its correct C5 character.
