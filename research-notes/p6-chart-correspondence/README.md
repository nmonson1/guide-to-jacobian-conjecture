# Program 6 chart correspondence: a first reduction and exact diagnostic

**Status:** research intake note, not an integrated claim or manuscript result.

This note develops the first part of Program 6 task P6-T2: replace fixed-chart surjectivity by a support-aware distinction between fixed-chart gauge and tangent directions to adjacent complete-chain charts. It gives:

1. a coordinate-free reduction of a normal-layer kernel to divergence-free source vector fields;
2. an elementary wall-shear correspondence lemma;
3. a finite formula for transporting Newton support under the wall shear;
4. a dependency-free exact diagnostic for the quotient by gauge and proposed rechart directions.

The note uses the universal normal-layer setup and the recorded `k = 4` transition `Y -> Y + lambda X^(-4)` as inputs. It does **not** reproduce the archived degree-21 matrices, classify all complete-chain transitions, or solve the global `F_2` attachment problem.

## 1. Kernel directions as divergence-free source fields

Let `K` be a characteristic-zero field and let `F = (P,Q): Spec A -> A^2` be generically etale, with `J(F) = det(dF) = c` in `K^*`. Work in any completed Laurent chart in which the displayed expressions are defined. For a first-order deformation `delta F = (a,b)`, define the rational source vector field

```text
v = (dF)^(-1) delta F.
```

### Proposition 1 (Keller kernel reduction)

The linearized determinant satisfies

```text
D_F J(delta F) = c div(v).
```

Consequently, the kernel of the determinant linearization is identified with the divergence-free rational vector fields `v` whose action `v(F) = (v(P),v(Q))` lies in the prescribed coefficient and support window.

#### Proof

Let `phi_t` be the formal flow with tangent vector `v`. The chain rule gives

```text
J(F o phi_t) = (J(F) o phi_t) J(phi_t).
```

Differentiating at `t = 0` gives

```text
D_F J(v(F)) = v(J(F)) + J(F) div(v).
```

Since `J(F) = c` is constant, the first term vanishes. Conversely, every `delta F` determines the unique rational `v = (dF)^(-1) delta F`.

This reformulates P6-T2. The hard part is no longer the determinant equation: it is the classification of divergence-free vector fields subject to the complete-chain filtration and finite support windows.

A general chart may have logarithmic de Rham classes, so “divergence-free” should not be silently replaced by “Hamiltonian.” For the recorded `k = 4` shear the vector field is Hamiltonian, but the logarithmic exception at `k = 1` must be retained in a general theorem.

## 2. Elementary wall-shear correspondence

Let `C` be a completed Newton chart with coordinates `(X,Y)`. Suppose an adjacent chart `C'` is related on the overlap by

```text
phi_lambda(X,Y) = (X, Y + lambda X^(-k)),    k >= 1.
```

The tangent vector at `lambda = 0` is `v_k = X^(-k) partial_Y`. It has zero divergence. For `k != 1` it is Hamiltonian with Hamiltonian `X^(1-k)/(k-1)`.

### Proposition 2 (elementary wall-shear lemma)

Assume:

- `F` is Keller and is defined in the overlap of `C` and `C'`;
- the shear is an admissible complete-chain transition from `C` to `C'`;
- `v_k(F)` lies in the normal-layer support window under consideration;
- `v_k` does not belong to the Lie algebra of fixed-chart admissible source operations in `C`.

Then `v_k(F)` lies in the normal-layer determinant kernel, is not induced by a fixed-chart admissible source vector field, and is the tangent direction of the adjacent-chart overlap.

#### Proof

The kernel assertion follows from Proposition 1 and `div(v_k)=0`. The overlap assertion is the derivative of `phi_lambda` at zero. If a fixed-chart vector field `u` induced the same deformation, then `(u-v_k)(P)=(u-v_k)(Q)=0`. Since `dP,dQ` are independent over the fraction field, `u-v_k=0`, contradicting the non-admissibility of `v_k` in the fixed chart.

This is a sufficient recognition theorem, not an exhaustive classification. The remaining problem is to prove that every residual supported divergence-free vector field is generated by fixed-chart operations, elementary adjacent-chart wall shears, and any explicitly retained logarithmic classes.

## 3. Exact support transport

To re-express an old-chart monomial in the adjacent coordinate `Y'`, write `Y = Y' - lambda X^(-k)`. Then

```text
X^i Y^j = sum_{t=0}^j binom(j,t) (-lambda)^t X^(i-k t) (Y')^(j-t).
```

Thus a finite support set `S` transports into

```text
T_k(S) = {(i-k t, j-t) : (i,j) in S, 0 <= t <= j}.
```

Ordering monomials by decreasing `Y`-degree makes the coefficient map triangular with diagonal one. On any finite support space closed under `T_k` and the inverse substitution, the overlap map is an exact linear isomorphism. This is the finite combinatorial object that should replace an informal claim that the rechart preserves support.

### Residue compatibility

Suppose a compatibility functional is represented by a residue `Res(lambda Phi)`. On an actual chart overlap, pull back both the adjoint principal part and the forcing form. Formal residue invariance gives

```text
Res(phi^*(lambda Phi)) = Res(lambda Phi).
```

Therefore residue conditions descend once the forcing term, adjoint element, and support window are transported together. Transporting only the kernel vector is insufficient.

## 4. The finite quotient to compute

At layer `r` in chart `C`, let

```text
H_r(C) = ker D_r,
B_r(C) = span of supported fixed-chart gauge vectors,
R_r(C) = span of supported tangent vectors of enumerated adjacent charts.
```

The diagnostic quantity is

```text
o_r(C) = dim H_r(C) - dim(B_r(C) + R_r(C)).
```

The desired first-complexity-drop theorem is `o_r(C)=0` through the relevant weight, together with exact support and residue transport for every generator of `R_r(C)`. A nonzero `o_r(C)` is not automatically an obstruction: it is an unclassified kernel direction and may signal a missing adjacent chart.

## 5. Exact diagnostic

`chart_correspondence.py` reads rational matrices and vectors from JSON and reports, for each layer:

```text
h_r = dim ker D_r,
b_r = dim B_r,
c_r = dim((B_r + R_r)/B_r),
o_r = dim(H_r/(B_r + R_r)).
```

It verifies that every supplied gauge and rechart vector lies in the kernel, returns exact quotient representatives, and computes `T_k(S)` for a specified support set. All arithmetic uses Python's `fractions.Fraction`.

Run:

```bash
python research-notes/p6-chart-correspondence/chart_correspondence.py \
  research-notes/p6-chart-correspondence/synthetic_k4_contract.json
python -m unittest discover -s research-notes/p6-chart-correspondence -p 'test_*.py'
```

The included fixture is deliberately synthetic. It matches the recorded residual dimensions `(1,2,1,1)` and places the final one-dimensional direction in the rechart span, but it does not reproduce the archived matrices.
