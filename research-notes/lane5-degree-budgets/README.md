# Lane 5 standard-filtration certificate and structural lemmas

This directory records a theorem for the **standard source-coordinate
filtration** of the displayed three-variable Keller map. It does not claim
coverage of arbitrary polynomial source automorphisms.

## Exact theorem

Let

```text
A0 = 1 + x*y
P  = A0^3*z + y^2*A0*(4+3*x*y)
Q  = y + 3*x*A0^2*z + 3*x*y^2*(4+3*x*y)
R  = 2*x - 3*x^2*y - x^3*z
```

and let `S=k[P,Q,R]` inside `B=k[x,y,z]`, where `k` has characteristic zero.
Then

```text
S intersect B_{<=6} = span_k{1,Q,R}.
```

Consequently the algebra generated by the degree-at-most-six filtered piece is

```text
k[S intersect B_{<=6}] = k[Q,R],
```

and has transcendence degree two.

This removes any target-polynomial-degree cutoff from the standard-presentation
calculation. It remains a fixed-source-coordinate theorem, not a full
left-right orbit theorem.

## Certificate

The source space `B_{<=6}` has the 84 monomials `x^i y^j z^k` with
`i+j+k<=6`. The certificate constructs 81 rational evaluation-difference
functionals from pairs of distinct source points in common fibers. Their
matrix has rank 81 modulo the prime `1000003`; the determinant of the selected
`81 x 81` pivot minor is

```text
214012 mod 1000003.
```

A nonzero modular minor is a nonzero rational minor. The exact coefficient
vectors of `1`, `Q`, and `R` annihilate all 81 rational rows. Hence the
rational kernel is exactly their three-dimensional span.

Every element of `k[P,Q,R]` is constant on every common-fiber pair. Therefore
any such element of source degree at most six belongs to this kernel. The
reverse inclusion is immediate because `deg Q<=6` and `deg R<=6`. Base change
gives the statement over every characteristic-zero field.

The rational split fibers are generated without solving a cubic numerically.
For distinct nonzero roots `a,b,c=-a-b`, a nonzero rational `h`, and a sign,
put

```text
C  = -h^2
s2 = a*b + a*c + b*c
s3 = a*b*c
r  = C*s3/2
q  = (4-C*s2)/(3*r)
p  = (-(16-18*q*r) +/- h^3*(a-b)*(a-c)*(b-c))/(54*r^2).
```

The inverse cubic is

```text
C(p,q,r)*x^3 + (4-3*q*r)*x - 2*r = 0,
C(p,q,r) = 27*p^2*r^2 - 18*p*q*r + 16*p + q^3*r - q^2,
```

and has the prescribed roots. For each root `x`, the source point is recovered
by

```text
t = x*((q-9*p*r)*x-2)/(x*(4-3*q*r)-3*r)
y = (t-1)/x
z = (2*x-3*x^2*y-r)/x^3.
```

The verifier checks all of these identities exactly with `Fraction`.

## Filtered differential obstruction

The transcendence-degree test has a useful refinement. For an embedded
inclusion `iota:A=k[u1,u2,u3] -> B`, a source automorphism `sigma`, and a degree
bound `D`, set

```text
F_D^sigma A = {a in A : deg sigma(iota(a)) <= D}.
```

Choose any basis `f1,...,fm` of this finite-dimensional space and define

```text
J_D^sigma =
  ideal of all 3 x 3 minors of (partial fi / partial uj).
```

This ideal is independent of the chosen basis. In characteristic zero:

1. `J_D^sigma=0` exactly when the algebra generated by `F_D^sigma A` has
   transcendence degree at most two.
2. If `F_D^sigma A` contains a polynomial coordinate frame of `A`, then
   `J_D^sigma=A`.
3. Therefore `J_D^sigma` being proper obstructs a degree-`D` coordinate frame.
4. The condition is strictly stronger than transcendence degree. For
   `F=span{u^2,u^3,v,w}` in `k[u,v,w]`, the generated algebra has
   transcendence degree three, but the differential-minor ideal is `(u)`.

Thus a residual “filtered conormal/Wronskian theorem” can be stated precisely
as proving that `J_6^sigma` is proper on every remaining source-normalization
case. The old certificate proves the stronger special condition `J_6=0` for
the standard source coordinates.

## No fixed automorphism-invariant finite-piece filtration

There is also a basic obstruction to the higher-Rees route. No exhaustive
filtration of `k[x1,x2,x3]` by finite-dimensional vector spaces can be
literally invariant under every polynomial automorphism. If `x1` belongs to
one finite piece, invariance under

```text
x1 -> x1 + x2^N
```

would place `x2^N` in that same piece for every `N`, a contradiction.

A useful generalized filtration must therefore be assigned **covariantly** to
the embedded pair, or be selected by a non-degree-increasing canonicalization.
It cannot be one fixed finite-piece filtration invariant under the full
polynomial automorphism group.
