# Lane 8 full-root queue audit

This directory is a research harness for the full-support `(8,28)` Newton root.
It does not assert the below-`125` exclusion, full-root emptiness, or an
adjacent-chart covering theorem.

The first stage recovers the executable sources embedded in the active public
Lane 8 packets and verifies every published packet/member SHA-256 value before
running anything. CI then records the real command-line contracts and uploads
the recovered sources. Subsequent commits use those exact sources to:

1. replay the truncated-root certificate independently;
2. regenerate the full-support layers and fifteen equations;
3. publish a denominator/saturation-aware stage manifest;
4. test the consequence map to the compact toric terminal system;
5. attempt the weakest adjacent-chart overlap theorem sufficient for Lane 8;
6. expose every surviving complement as an explicit queue node.

Two boundaries are fixed from the outset:

- a reduced set-theoretic routing statement is not silently upgraded to a
  scheme-level statement about the square occurring at layer four;
- the previously proposed bare `k=4` wall shear is not used as a layer-four
  bridge, because its first lower-face contribution occurs at layer seven.

Any final closure claim must be generated from a proof-carrying DAG whose
nonterminal nodes are covered by their children and whose terminal nodes carry
replayable exact certificates.
