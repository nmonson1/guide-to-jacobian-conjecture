# The Missing Layer-Four Operation Is the k=4 Newton-Chart Transition

<p class="dek">For the stored degree-21 terminal face, the one-dimensional layer-four residual kernel is not realized by a fixed-chart algebraic operation; it is the k=4 complete-chain rechart, after which the adjacent-chart Jacobian equations force L=0, F5=0, and a common approximate root P2=C R^2, Q3=G R^3.</p>

## Exact statement

For the stored degree-21 terminal face, the one-dimensional layer-four residual kernel is not realized by a fixed-chart algebraic operation; it is the k=4 complete-chain rechart, after which the adjacent-chart Jacobian equations force L=0, F5=0, and a common approximate root P2=C R^2, Q3=G R^3.
