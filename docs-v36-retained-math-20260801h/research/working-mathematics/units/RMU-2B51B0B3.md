A pair \(A,B\in\C[c]\) is admissible if
\[
A(0)=0,\quad A'(0)=1,\qquad
B(0)=-2,\quad B'(0)=-2A''(0).
\]
Using
\[
c=2x-3x^2y-x^3z,\qquad
t=y+\frac1x,\qquad r=\frac2x,
\]
define \(G_{A,B}=(a,b,c)\) by
\[
b=r-3A(c)t^2-2B(c)t,\qquad
2a=A(c)t^3+B(c)t^2+tb.
\]
