# Degree Eight Deformations

<p class="dek">For the degree-eight local Kuranishi problem, the residual 28-dimensional slice reduces to weights -2 and -1; weight -2 is eliminated over Q, while weight -1 survives to fourth order and has only modular death evidence at order six.</p>

## Precise statement

For the degree-eight local Kuranishi problem, the residual 28-dimensional slice reduces to weights -2 and -1; weight -2 is eliminated over Q, while weight -1 survives to fourth order and has only modular death evidence at order six.
