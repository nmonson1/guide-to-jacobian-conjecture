# The Jacobian Conjecture: A Guide

Source for a hand-authored public guide to the Jacobian conjecture, the 2026
counterexample in dimension three, the surviving plane problem, and the
research landscape opened by the example.

The guide is written by Nathaniel Monson, with project-wide AI assistance
disclosed in `docs/about/ai-assistance.md`.

The guide is intentionally not a mirror of the research-state repository.
That repository owns detailed proofs, computations, working claims, and
research lanes. This repository owns useful public exposition: a short start
path, mathematical-ideas essays, research-front narratives, selective major
results, and a source-based catalogue of external developments.

## Editorial publication model

Every Markdown page in `docs/` is public and hand-authored. A page can be
shared by direct URL before it is listed. Ordinary navigation, the main search
index, and the sitemap contain only exact file versions recorded as approved
in `editorial/reviews.json`.

The effective states are:

- `unread`;
- `needs_revision`;
- `approved`; and
- `changed_since_review`, computed automatically when an approved file's
  SHA-256 hash no longer matches.

This is owner editorial review, not mathematical peer review.

```bash
python scripts/review_pages.py status
python scripts/review_pages.py approve docs/start/counterexample.md
python scripts/review_pages.py needs-revision docs/fronts/index.md
```

`editorial/navigation.json` is the hand-authored intended navigation order.
The MkDocs hook builds every page, filters the reader-facing surfaces, and
produces the unlisted reviewer index at `/review/`.

An approved page may not link to an unapproved page. This keeps drafts from
leaking back into ordinary browsing through inline links and makes the
approval order explicit: approve dependencies before the pages that route to
them. The review workspace itself is shared only by direct URL.

## Local build

With [`uv`](https://docs.astral.sh/uv/) installed:

```bash
uv run --with-requirements requirements.txt python -m unittest discover -s tests
uv run --with-requirements requirements.txt python scripts/check_site.py
uv run --with-requirements requirements.txt mkdocs build --strict --site-dir /tmp/jacobian-guide-preview
uv run --with-requirements requirements.txt python scripts/check_built_site.py /tmp/jacobian-guide-preview
```

GitHub Actions deployment is manual while hosted checks are disabled. No raw
conversations, private research records, autogenerated mathematical prose,
or generated claim corpus belongs in this repository.
