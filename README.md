# The Jacobian Conjecture: A Guide

Source for a human-directed, owner-edited guide to the Jacobian conjecture,
the 2026 counterexample in dimension three, the surviving plane problem, and
the research landscape opened by the example. Project-wide AI assistance is
disclosed in `docs/about/ai-assistance.md`; the site is written as mathematical
exposition rather than generated from a claim corpus.

The repository separates two public functions:

- the **reading layer** explains formulas, geometric pictures, mathematical
  ideas, research questions, and selected major results;
- the **audit layer** records primary sources, evidence type, publication
  status, chronology, attribution, and theorem scope.

Detailed proofs, computations, working claims, and technical research lanes
belong in the research-state repository or in pinned public manuscripts.

## Editorial publication model

Every Markdown page in `docs/` is public and can be shared by direct URL.
Ordinary navigation, site search, and the sitemap contain only exact file
versions recorded as approved in `editorial/reviews.json`.

The effective states are:

- `unread`;
- `needs_revision`;
- `approved`;
- `changed_since_review`, computed when an approved file's SHA-256 hash no
  longer matches.

This is owner editorial review, not mathematical peer review.

```bash
python scripts/review_pages.py status
python scripts/review_pages.py approve docs/start/counterexample.md
python scripts/review_pages.py needs-revision docs/fronts/index.md
```

`editorial/navigation.json` gives every public page a section and its intended
order. The MkDocs hook builds every page, filters reader-facing surfaces, and
produces the unlisted reviewer index at `/review/`.

An approved page may not link to an unapproved page, so dependencies are
approved before the pages that route to them.

## Expository conventions

Substantive pages should begin from a question, phenomenon, example, or
concrete object. They should expose the causal mechanism, use diagrams where
a picture carries mathematical content, and name the genuinely surprising
step. Generic result templates and repeated limitation sections are replaced
by headings that belong to the mathematics. Proof and status material appears
once in `docs/results/evidence-ledger.md`.

See `editorial/expository-style.md` for the working style guide. The
non-blocking `scripts/audit_prose.py` reports repeated negative contrasts,
generic headings, and metadiscourse for human review.

## Local build

With [`uv`](https://docs.astral.sh/uv/) installed:

```bash
uv run --with-requirements requirements.txt python -m unittest discover -s tests
uv run --with-requirements requirements.txt python scripts/check_site.py
uv run --with-requirements requirements.txt mkdocs build --strict --site-dir /tmp/jacobian-guide-preview
uv run --with-requirements requirements.txt python scripts/check_built_site.py /tmp/jacobian-guide-preview
```

GitHub Actions deployment is manual while hosted checks are disabled. Raw
conversations, private research records, autogenerated mathematical prose,
and generated claim corpora do not belong in this repository.
