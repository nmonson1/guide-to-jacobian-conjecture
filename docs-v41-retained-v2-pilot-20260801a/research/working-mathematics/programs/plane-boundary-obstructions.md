## Setup and research posture

This program studies the boundary geometry of a hypothetical plane Keller
pair through Newton faces, approximate roots, complete-chain rechartings,
normal-layer complexes, and finite terminal systems. Three obligations must
remain independently visible: the terminal computation, exhaustiveness of
the face/chart queue, and descent or attachment to a global polynomial map.

Unrestricted formal normal coordinates decouple the determinant equation,
but they need not preserve sparse Newton support or the admissible
approximate-root subgroup. Residual kernel directions may be genuine chart
transitions rather than fixed-chart gauge. The stored transition is a model
for the general correspondence theorem, not a substitute for it.

## Strategy and payoff

The upstream audit should regenerate every lower face, saturation,
normalization, deficiency layer, recharting, and branch split from raw
supports. Maintain a stage manifest and record branch conditions before any
specialization. Each terminal input needs a provenance edge from the global
queue.

In parallel, define the admissible filtered action complex: the actual gauge
subgroup, rechart operations, support transformation, quotient obstruction
space, and transport on overlaps. Full Laurent vector fields are too large;
ordinary affine-polynomial fields give the wrong ranks. The complete-chain
subgroup is the missing definition.

The flexible branch must be approached as a two-sided attachment problem
with every fresh kernel coordinate retained. A successful global attachment
would be a candidate counterexample and should immediately replace
obstruction language.

## Connections

The distinction between local charts and global equivalence parallels the
stable-moduli gluing problem. Filtered action and obstruction complexes
connect to local deformation algebra. Exact terminal programs are a useful
test case for the retained graph's separation of computation contracts from
geometric scope.

## Current priorities and research freedom

The current attention order is:

1. regenerate and audit the complete lower-face pipeline;
2. prove a general gauge-versus-rechart correspondence theorem;
3. conjugate support-aware residue equations through exact normal
   coordinates; and
4. solve the full global attachment problem for the long-lived flexible
   branch using the actual data blocks.

- Finite-order Puiseux rigidity fails for the analyzed recurrence.

  not terminal invariants.
