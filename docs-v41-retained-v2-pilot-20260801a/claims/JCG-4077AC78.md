# Binary Linear Fixed Factors Are Automorphic

<p class="dek">Assume the Program 2 reductions reach a binary leading pencil whose greatest common divisor is a line. After normalization H4=(x^4,xB,0), with B a binary cubic not divisible by x, every quartic Keller map in the stratum is a polynomial automorphism.</p>

## Exact statement

Assume the Program 2 reductions reach a binary leading pencil whose greatest common divisor is a line. After normalization H4=(x^4,xB,0), with B a binary cubic not divisible by x, every quartic Keller map in the stratum is a polynomial automorphism.
