# Every polynomial map from complex affine n-space to itself whose Jacobian determinant…

`JCG-21418592` · `assertion` · statement version `1`

## Exact statement

Every polynomial map from complex affine n-space to itself whose Jacobian determinant is a nonzero constant is a polynomial automorphism.
