# Corrections and missing work

Please report mathematical errors, unclear explanations, broken proof
routes, attribution problems, and missing external contributions.

- [Open a correction issue](https://github.com/nmonson1/guide-to-jacobian-conjecture/issues/new?template=correction.yml)
- [Submit a missing source or development](https://github.com/nmonson1/guide-to-jacobian-conjecture/issues/new?template=source.yml)
- [Propose a pull request](https://github.com/nmonson1/guide-to-jacobian-conjecture/pulls)

A useful report identifies the page and sentence, gives a primary source
when possible, and distinguishes “the statement is false” from “the cited
source does not establish the statement as written.”

Credit corrections are handled conservatively. If a source shows that an
external result predates the project's version, the public page will credit
the earlier source and omit the later duplication. The repository history
remains available for priority questions without turning the guide into a
priority ledger.
