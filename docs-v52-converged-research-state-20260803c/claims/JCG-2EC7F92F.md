# On det(T) nonzero, the five-dimensional full-kernel pencil has Jordan type (5) everywhere…

<p class="dek">On det(T) nonzero, the five-dimensional full-kernel pencil has Jordan type (5) everywhere exactly when a7 is nonzero; after setting lambda=a7, its parameter space is the principal sl2-module C lambda plus Sym^6(C^2), with det(T)=((lambda^2+4A)^2-96B)/256.</p>

## Exact statement

On det(T) nonzero, the five-dimensional full-kernel pencil has Jordan type (5) everywhere exactly when a7 is nonzero; after setting lambda=a7, its parameter space is the principal sl2-module C lambda plus Sym^6(C^2), with det(T)=((lambda^2+4A)^2-96B)/256.
