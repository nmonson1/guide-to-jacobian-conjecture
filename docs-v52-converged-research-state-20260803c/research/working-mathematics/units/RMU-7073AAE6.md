# The \((4,17)\) cover

`RMU-7073AAE6` · `corollary` · statement version `1`

## Exact statement

For \(a=4,e=17\),
\[
H_{4,17}(s)
=\frac{195+240s+320s^2+512s^3+2048s^4}{3315},
\]
\[
W_{4,17}(s)=\frac{(s-1)H_{4,17}(s)^4}{s^{17}},
\qquad
W_{4,17}'(s)=\frac{H_{4,17}(s)^3}{s^{18}},
\]
with passport \((4^4,1),(17),(5,1^{12})\).
