# Omitted Locus And Smoothness

<p class="dek">For every complex polynomial Keller map, the omitted-value locus is contained in the singular locus of the reduced nonproperness set.</p>

<span class="status status-kind">Result</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

For every complex polynomial Keller map, the omitted-value locus is contained in the singular locus of the reduced nonproperness set.

## Claims in this result package

### [JCG-0A41960D · For every complex polynomial Keller map, the omitted-value locus is contained in…](../claims/JCG-0A41960D.md)

For every complex polynomial Keller map, the omitted-value locus is contained in the singular locus of the reduced nonproperness set.

*Defining · Primary Statement · Proof supplied*

### [JCG-BF1A2DBF · If a generic-degree-three Keller map had smooth irreducible nonproperness hypersurface, then…](../claims/JCG-BF1A2DBF.md)

If a generic-degree-three Keller map had smooth irreducible nonproperness hypersurface, then it would be surjective, the hypersurface would be isomorphic to A2, and its discriminant double cover would admit a connected etale C3-cover.

*Defining · Immediate Corollary · Recorded*

### [JCG-E82019D2 · For an omitted value p of a complex Keller map F from…](../claims/JCG-E82019D2.md)

For an omitted value p of a complex Keller map F from A3 to A3, the direction map x maps to [F(x)-p] from A3 to P2 is smooth of relative dimension one and has image equal to P2 minus at most finitely many points.

*Defining · Supporting Result · Proof supplied*
