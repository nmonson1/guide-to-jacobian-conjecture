# Leading Curves and Normal Resonance at Infinity

<p class="dek">For a quartic Keller deformation of a leading curve, the first nonzero normal coefficient below determinant order nine can occur only at an order divisible by the homogeneous period; in the primitive period-four case the first three normal coefficients vanish.</p>

<span class="status status-kind">Result</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

For a quartic Keller deformation of a leading curve, the first nonzero normal coefficient below determinant order nine can occur only at an order divisible by the homogeneous period; in the primitive period-four case the first three normal coefficients vanish.
