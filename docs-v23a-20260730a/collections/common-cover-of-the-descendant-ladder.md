# The Common Cover of the Descendant Ladder

<p class="dek">The original three-variable map has the displayed invariant quotient cubic theta^3-2theta^2+Btheta-2A, whose irreducibility and nonsquare discriminant give generic Galois group S3; the descendant ladder presents this same three-sheeted cover.</p>

<span class="status status-kind">Result</span> <span class="status status-draft">Draft Public</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

The original three-variable map has the displayed invariant quotient cubic theta^3-2theta^2+Btheta-2A, whose irreducibility and nonsquare discriminant give generic Galois group S3; the descendant ladder presents this same three-sheeted cover.
