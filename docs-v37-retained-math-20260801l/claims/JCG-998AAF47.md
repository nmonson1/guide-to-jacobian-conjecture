# For a quartic Keller map with leading line H4=(P,Q,0), the first nonzero normal layer Nm is algebraic but not rational over C(P,Q), and the characteristic-field extension has degree at least 4/gcd(4,m).

## Exact statement

For a quartic Keller map with leading line H4=(P,Q,0), the first nonzero normal layer Nm is algebraic but not rational over C(P,Q), and the characteristic-field extension has degree at least 4/gcd(4,m).
