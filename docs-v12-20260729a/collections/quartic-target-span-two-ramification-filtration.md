# The Quartic Target-Span-Two Ramification Filtration

<p class="dek">The quartic search is reduced to target span two. Regular, genuinely nonbinary quadratic-source, simple-ramification, and double-ramification strata are excluded under the manuscript's stated structural inputs; the triple branch is only partially reduced.</p>

<span class="status status-kind">Result</span> <span class="status status-draft">Draft Public</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

Assuming the Program 2 structural inputs, a quartic Keller map in the coprime binary-pencil locus is a polynomial automorphism whenever deg gcd(J(Q,R),J(P,R),J(P,Q)) is at most two.

Subject to the leading-curve reductions in the Program 2 manuscript, any nonautomorphic quartic Keller map in three variables has leading target span exactly two.

### [JCG-1AE58E51 · Regular Binary Quartic Pencils Are Automorphic](../claims/JCG-1AE58E51.md)

In the binary target-span-two locus, if U=J(Q,R), V=J(P,R), and W=J(P,Q) are all nonzero and gcd(U,V,W)=1, then the quartic Keller map is a polynomial automorphism.
