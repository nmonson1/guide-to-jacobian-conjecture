# The Exceptional q=-2 Member Is a Weighted-Jacobian Stratum

<p class="dek">For A=c(c+1), B=-2(c+1)^2, the pulled-back relative Jacobian ideal is generated by (c+1)^2(3ct-2(c+1))^3, so the exceptional member is uniformly recorded by vertical multiplicity two.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof supplied</span> <span class="status">Core</span>

## Exact statement

For A=c(c+1), B=-2(c+1)^2, the pulled-back relative Jacobian ideal is generated by (c+1)^2(3ct-2(c+1))^3, so the exceptional member is uniformly recorded by vertical multiplicity two.
