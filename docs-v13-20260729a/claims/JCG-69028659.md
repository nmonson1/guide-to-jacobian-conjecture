# The Smooth Cubic-Axis Resolvent Model Is Flat

<p class="dek">In the stated one-parameter smooth cubic-axis hypersurface model, when the transverse three-torsion class extends as a section of the relative three-torsion group scheme, its rank-one reflexive module is maximal Cohen-Macaulay and the associated cubic normalization is flat.</p>

## Exact statement

In the stated one-parameter smooth cubic-axis hypersurface model, when the transverse three-torsion class extends as a section of the relative three-torsion group scheme, its rank-one reflexive module is maximal Cohen-Macaulay and the associated cubic normalization is flat.
