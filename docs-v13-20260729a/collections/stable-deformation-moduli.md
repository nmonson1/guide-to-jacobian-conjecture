# Stable Deformation Moduli

<p class="dek">For the quadratic cubic-frame slice with alpha nonzero, q=beta/alpha^2 is a complete invariant under arbitrary polynomial source-target equivalence and stabilization; the alpha=0 line is gauge-equivalent to the base map.</p>

## Precise statement

For the quadratic cubic-frame slice with alpha nonzero, q=beta/alpha^2 is a complete invariant under arbitrary polynomial source-target equivalence and stabilization; the alpha=0 line is gauge-equivalent to the base map.
