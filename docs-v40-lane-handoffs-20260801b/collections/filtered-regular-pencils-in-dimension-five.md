# Filtered Regular Nilpotent Pencils in Dimension Five

<p class="dek">An everywhere-regular five-dimensional quadratic nilpotent line pencil whose kernel map spans P4 has saturated filtration degrees (-4,-2,0,2,4); every successive map is an isomorphism and the kernel map is the rational normal quartic.</p>

<span class="status status-kind">Result</span> <span class="status status-draft">Draft Public</span> <span class="status coverage-complete">Exact manuscript location</span>

## Precise statement

An everywhere-regular five-dimensional quadratic nilpotent line pencil whose kernel map spans P4 has saturated filtration degrees (-4,-2,0,2,4); every successive map is an isomorphism and the kernel map is the rational normal quartic.
