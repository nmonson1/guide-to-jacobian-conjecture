# An Omitted Value Defines a Smooth Direction Fibration

<p class="dek">For an omitted value p of a complex Keller map F from A3 to A3, the direction map x maps to [F(x)-p] from A3 to P2 is smooth of relative dimension one and has image equal to P2 minus at most finitely many points.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof offered — review pending</span> <span class="status">Core</span>

## Exact statement

For an omitted value p of a complex Keller map F from A3 to A3, the direction map x maps to [F(x)-p] from A3 to P2 is smooth of relative dimension one and has image equal to P2 minus at most finitely many points.
