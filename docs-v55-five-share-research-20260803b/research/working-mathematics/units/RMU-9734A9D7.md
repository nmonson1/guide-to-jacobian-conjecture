# Exact regularity criterion

`RMU-9734A9D7` · `proposition` · statement version `1`

## Exact statement

On \(\det T\ne0\), the pencil \(M(s,t)\) has Jordan type \((5)\) at every
point of \(\PP^1\) if and only if \(a_7\ne0\).

nonzero exactly when \(a_7\ne0\).
