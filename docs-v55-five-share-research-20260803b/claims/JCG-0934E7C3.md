# If an n-dimensional homogeneous map has a k-dimensional partial-gradient block, it admits…

<p class="dek">If an n-dimensional homogeneous map has a k-dimensional partial-gradient block, it admits a weak symmetric dilation in dimension at most 2n-k; in particular every polynomial map has weak symmetric-dilation dimension at most 2n-1.</p>

<span class="status status-kind">Claim</span> <span class="status status-draft">Proof supplied</span> <span class="status">Core</span>

## Exact statement

If an n-dimensional homogeneous map has a k-dimensional partial-gradient block, it admits a weak symmetric dilation in dimension at most 2n-k; in particular every polynomial map has weak symmetric-dilation dimension at most 2n-1.
