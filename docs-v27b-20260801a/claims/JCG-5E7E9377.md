# Zero-Minor Binary Quartic Boundaries Are Automorphic

<p class="dek">Assume the Program 2 binary target-span-two reduction. If one of U=J(Q,R), V=J(P,R), or W=J(P,Q) vanishes, including the separate case R=0, then the quartic Keller map is a polynomial automorphism. Consequently the ordinary common-ramification filtration may be applied only after these zero-minor boundaries are removed.</p>

## Exact statement

Assume the Program 2 binary target-span-two reduction. If one of U=J(Q,R), V=J(P,R), or W=J(P,Q) vanishes, including the separate case R=0, then the quartic Keller map is a polynomial automorphism. Consequently the ordinary common-ramification filtration may be applied only after these zero-minor boundaries are removed.
